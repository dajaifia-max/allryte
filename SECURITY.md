# Security policy

## Reporting a vulnerability

Before launch, replace this section with the practice's monitored security contact and response expectations. Do not include patient or clinical information in a vulnerability report.

## Patient information boundary

This repository is designed so the public website does not receive, store, or process patient information. Patient communication and records must remain inside an approved portal/EHR covered by the practice's security review and applicable BAAs.

See `docs/SECURE-PORTAL-HANDOFF.md` for configuration and go-live requirements.
